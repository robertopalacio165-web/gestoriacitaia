# Reels Studio — أرشيف التحرير الاحترافي ديال الريلز (MIDO CARS × PALACIO CARS)

## كيفاش تستعملو
1. فتح Claude Code ف المشروع اللي فيه هاد الأرشيف (`.claude/skills/reels-studio` + `.claude/agents`).
2. عطي الفيديو وقول: **"دير ليا الريل بالستايل ديالنا (house style)"**.
3. Claude كيقرا `SKILL.md` و `references/house-style.md` وكيبدا من
   `references/examples/house_style_60s_plan.json`.

## شنو فيه
- `SKILL.md` — القواعد والفريق (4 الناس: المونتير، الموشن ديزاينر، الساوند ديزاينر، مول الكتابة)
- `references/house-style.md` — الستايل المعتمد: بلا ترجمة، بلا موسيقى، ما كاين والو فوق الطوموبيلات، خط Tajawal،
  checklist ذهبي عريض، compteur ديال الأثمنة، النمر ف الوسط وف اللخر
- `assets/motion/templates.html` — موشن GSAP: price_counter, kinetic, lower_third, flags, cta, light_wipe,
  notification, sale_badge, doodle, progress_ring, map_pins, marker_words, whatsapp_contacts, contact
- `assets/lottie/` — 24 إيموجي متحرك ديال Google
- `scripts/` — المحرك (reelkit.py, gfx.py, motionlib.py, motion_render.js)
- `../../agents/reels-*.md` — الـ 4 الناس
